# 对标抓取与脚本生成流程（固定 SOP）

> 这是从「用户给一个对标链接」到「产出 TXT + Word + HTML」的完整流程。
> 所有步骤都在 `D:\kaifa\xmt` 下执行，Python 一律用 `.venv/Scripts/python.exe`。
> 最后更新：2026-10-23

---

## 第 0 步：明确四个输入

开工前先问清/确认：

| 项 | 说明 |
|---|---|
| **对标链接** | 抖音要**主页分享短链**（如 `https://v.douyin.com/xxxxx/`）。只有抖音号不够，搜索页有验证码、接口要签名，**拿不到数据** |
| **账号** | 口播号（翔哥）/ 品牌号（心悦+小冯，也可单人）/ 个人号（小冯）。**人设卡是硬约束** |
| **产品** | 具体型号 or 不代入产品。型号必须能在 `docs/产品参数档案.md` 里找到 |
| **数量与风格** | 几篇、要不要更简单、角度要不要不同、收尾要不要不同 |

---

## 第 1 步：抓对标账号

```bash
# 1a. 短链 → sec_uid（关键：分享页 URL 里就带 sec_uid）
.venv/Scripts/python.exe -c "
import sys; sys.path.insert(0,'tools')
from capture_douyin import resolve
vid,url,title = resolve('<短链>')
print(url)"

# 1b. 账号信息（昵称/抖音号/签名/关注/作品数）
.venv/Scripts/python.exe tools/probe_douyin_profile.py <sec_uid> 12

# 1c. 作品列表（★ profile 抓不到列表，必须用 items）
.venv/Scripts/python.exe tools/probe_douyin_items.py <sec_uid> 15
```

**挑选代表作**：优先挑高赞的（如 126 赞）、不同角度的（介绍型/实测型/故事型）、
时长 20-60 秒的。挑 3-4 条。

---

## 第 2 步：抓视频直链并转写

```bash
# 2a. 抓直链并下载（★ 必须带完整 URL，裸 videoId 会报 MissingSchema）
.venv/Scripts/python.exe tools/capture_douyin.py "https://www.douyin.com/video/<videoId>"

# 2b. 转 wav（先确认有没有音频：纯字幕视频会报 "does not contain any stream"）
ffmpeg -y -i out/sph_dl/douyin_<id>.mp4 -vn -ac 1 -ar 16000 \
       -c:a pcm_s16le out/sph_dl/douyin_<id>.wav

# 2c. 本地 Whisper 转写（免 RedFox 积分）
.venv/Scripts/python.exe tools/local_asr2.py out/sph_dl/douyin_<id>.wav medium
```

**⚠️ 两个已知坑**：
1. 转写脚本末尾写 `_转写.txt` 会被沙箱拦（PermissionError），但 **stdout 全文照样拿得到**，
   直接把输出抄进分析文档即可。
2. `--model tiny` 会 502（权重没缓存 + hf-mirror 走代理被挡），**用默认 `medium`**。

---

## 第 3 步：写账号分析文档

存到 `.workbuddy/skills/scriptgen-writing/对标账号分析-<账号名>.md`，必含五节：

1. **账号基本面**：昵称/抖音号/sec_uid/签名/关注/作品数/定位
2. **代表作逐句转写**（带时间戳，**要逐句不要只给全文**）
3. **风格拆解**：语言特征（人称/口头禅/句式）+ 骨架（分步骤列）+ 标题公式 + 选题库 + 时长字数
4. **合规雷区表**：他的原话 → 踩哪条规则 → 我们的改法
5. **套用建议**：哪个骨架优先、哪些参数不能抄

> ★ 同一矩阵的不同出镜号要写清差异（如陈大脸=老板视角参数多，王师傅=从业者视角句子短）。

---

## 第 4 步：查产品参数

**先查 `docs/产品参数档案.md`**，里面已有型号直接用；
没有的先跑（词要多用正式词，2-3 个词最稳，全词 AND）：

```bash
.venv/Scripts/python.exe -c "
from scriptgen.company_kb import CompanyKB
kb=CompanyKB()
for h in kb.search('<型号> <品类>', top_k=8): print(h.get('doc_id'))
print(kb.read_text('<doc_id>', max_chars=6000))"
```

**注意**：
- 参数文档可能只写卖点不写数字（NIP 就是），数字要去**营销文案/配文**里找，多源交叉核对
- `kb.read` 默认 max_chars 约 5K 会截断，长文档用 `offset=4000` 再读一段
- 查到的参数**补回档案 md**，下次不用再查
- ⚠️ **竞品参数绝不抄**：对标杆子里的 16 公斤/12 公里/陀螺仪是人家自己产品的，跟我们无关

---

## 第 5 步：查人设卡（硬约束）

```bash
.venv/Scripts/python.exe -c "
import json
d=json.load(open('config/personas.json',encoding='utf-8'))
for p in d['personas']:
    if p['id']=='<oral|brand|personal>': print(p['identity'], p['duration'], p['cta_style'])"
```

| id | 身份 | 时长/字数 | CTA |
|---|---|---|---|
| `oral` 口播号·翔哥 | 十年养老辅具·邻居家懂行 | 60-90s / 260-400 | 关注/转给 |
| `brand` 品牌号·心悦+小冯 | 一问一答（**也可单人**） | 30-45s / 150-240 | 到店试车 |
| `personal` 个人号·小冯 | 工厂店·朴实带口音 | 45-60s / 200-280 | 来展厅 |

**长度口径**：贴对标（对标时长 80%-120%），同时 `target_seconds` 必须落在人设区间内。
用户说「简单一点」时，字数往下压一档（如 150-200 字 / 36-48 秒）。

## 第 6 步：写稿（贴对标原句改写）

铁律：**骨架照搬，词换近义；只动三类：换词、调位、替内容。**

1. 拿对标**逐句带时间戳**的 segments，按句子建骨架
2. 一句对一句替换成我们的近义表达，**不能出现照抄原词的句子**
3. 产品参数从档案取，不串型号
4. 合规词先过一遍：不写价格、不写绝对化（轻轻松松/最/非常安全）、
   不写疾病名、不写「更安全/更稳」类安全断言、不写终身售后
5. **收尾句全库去重**（用户明确要求批量稿最后一句必须不同）

写稿脚本模板见 `tools/make_nip_personal.py` / `tools/make_p10_personal.py`：
一个脚本 = 一个 BATCH 列表（code/title/lines/tips）+ FACT_TEXT + 合规扫描。

```bash
.venv/Scripts/python.exe tools/<新脚本>.py
# 输出里看：字数 / 秒数 / 合规 counts（高危中危必须为 0）
```

## 第 7 步：落库并渲染产出

```bash
# 7a. 渲染 md + Word
.venv/Scripts/python.exe -c "
import sys,sqlite3; sys.path.insert(0,'.')
from scriptgen import store, pipeline
con=sqlite3.connect('data/xmt.db'); con.row_factory=sqlite3.Row
for code in ['<CODE1>','<CODE2>']:
    s=store.get_script(con,code)
    store.update_script(con, code, file_path=store.script_path(s)); con.commit()
    pipeline._render_script(con, code)
con.close()"
```

**⚠️ Word 序号要接在 out/ 里最大号后面**。`store.docx_path()` 用的是数据库 id，
新记录 id 会比 out 里的连续编号大（比如 id=81 → 081），跟已有文件对不上：

```bash
# 7b. 手动重命名 + 回写数据库
cd out && mv "081_个人号_<标题>.docx" "078_个人号_<标题>.docx"
.venv/Scripts/python.exe -c "
import sqlite3
con=sqlite3.connect('data/xmt.db')
con.execute('update sg_scripts set docx_path=? where code=?',
            ('D:/kaifa/xmt/out/078_个人号_<标题>.docx','<CODE>'))
con.commit()"
```

## 第 8 步：刷全部产出（一条都不能少）

```bash
# 8a. 把新 code 加进 tools/export_standalone.py 的 ORDER 列表（按账号插到对应组末尾）
.venv/Scripts/python.exe tools/export_standalone.py   # 生成 稿子/<账号>/<序号>_<标题>.txt
.venv/Scripts/python.exe tools/archive_scripts.py     # 生成 对照表/*.html
```

**产出四件套**：
| 产物 | 位置 |
|---|---|
| 单独 TXT | `稿子/{口播号\|品牌号\|个人号}/<账号内序号>_<标题>.txt` |
| Word | `out/<全局序号>_<账号>_<标题>.docx` |
| 源 md | `out/scripts/<日期>/<账号id>/<CODE>_<标题>.md` |
| HTML 对照表 | `对照表/index.html` + `对照表/对标对照表-<账号>.html` |

## 第 9 步：质量自查清单

- [ ] 合规扫描：高危 0、中危 0
- [ ] 字数/秒数落在人设区间（或按用户要求压过一档）
- [ ] 收尾句跟库内其他稿不重复
- [ ] 产品参数能回溯到档案/doc_id，**没抄竞品参数**
- [ ] 手动款稿里无电动词（电机/电池/摇杆/电磁刹车/瓦/续航/遥控）
- [ ] 使用场景真实成立（别写「吃饭的时候怎么坐」这种不成立的）
- [ ] Word 序号接续、TXT 序号按账号连续、HTML 已刷新
