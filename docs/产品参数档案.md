## 三、跨产品串参高危点（写稿必查）

这些参数「长得像」但归属不同，抄错一次就被用户抓：

| 参数 | 归属 | 别抄到 |
|---|---|---|
| 15.8 公斤 / 15 公里 / 340W / 10股弹簧 | **P10** | F2Q、P11 |
| 19 公斤 / 240W / 六重保护 / 44cm | **F2Q** | P10、朋友2 |
| 7.8 公斤 / 150kg 承重 / 810-913mm / 千鸟格 | **NIP** | 朋友2、减震款 |
| 8.9 公斤 / 8档+7档 | **助行器减震款** | 朋友2 |
| 16 公斤 / 12 公里 / 陀螺仪 / 大阻尼康复模式 | **王师傅那台四合一代步车（竞品）** | 我们任何产品 |
| 30 度坡 / 3cm 门槛 | P10、F2Q 各有说法，按各自档案写 | 别跨型号搬 |

**写完自查命令**（把某产品稿里不该出现的电动词全扫一遍）：
```bash
.venv/Scripts/python.exe -c "
import sqlite3
con=sqlite3.connect('data/xmt.db')
bad=['电机','电池','摇杆','电磁刹车','瓦','AH','锂电','续航','遥控']
for r in con.execute(\"select code,title,body_md from sg_scripts where product_model like '%NIP%'\"):
    print(r[1],'->',[w for w in bad if w in r[2]] or '干净')
"
```
