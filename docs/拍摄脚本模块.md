# 拍摄脚本模块（scriptgen）

> 2026-10-20 上线。给佳康顺三号矩阵（口播号 / 品牌号 / 个人号）做**对标视频 → 口播逐字稿**的本地工具。

## 一句话

你发抖音/视频号链接，模块自动提取文案和元数据、存进本地知识库、拆结构、判断给哪个号、从阳光展厅可拍产品里选品，最后出一条**原创口播逐字稿 + 3-5 条拍摄提示**。不再生成三平台标题/标签/封面发布包。

## 快速开始

```bash
# 初始化表与目录（首次）
.venv/Scripts/python.exe -m scriptgen init

# 对话里发链接给 Claude，底层执行：
.venv/Scripts/python.exe -m scriptgen add "https://v.douyin.com/xxxx/
https://weixin.qq.com/sph/xxxx"

# 只估算，不调用
.venv/Scripts/python.exe -m scriptgen estimate "<链接...>"

# 批次里低置信度的条目，人工选完账号/产品后补写
.venv/Scripts/python.exe -m scriptgen resolve B-20261020-141036-31b3 --choice "1:personal:F2Q"

# 审核
.venv/Scripts/python.exe -m scriptgen approve SG-20261020-001
.venv/Scripts/python.exe -m scriptgen revise SG-20261020-002 --instruction "开头再直一点，目标 60 秒"

# 同步公司知识库（只允许已通过；dry-run 不写）
.venv/Scripts/python.exe -m scriptgen sync SG-20261020-001 --dry-run
.venv/Scripts/python.exe -m scriptgen sync SG-20261020-001

# 检索本地脚本/对标/转写
.venv/Scripts/python.exe -m scriptgen search 折叠
```

## 对话里的实际用法

```
你：口播号：<视频号链接>
我：调用 scriptgen add → 提取 → 判号 → 出稿 → 给路径

你：这条用个人号，F2Q
我：resolve 批次条目 → 出稿

你：开头再狠一点，压到 50 秒
我：revise → 新版本，保留旧版

你：通过
我：approve

你：同步
我：sync 到公司知识库 marketing
```

不确定账号或产品时，模块不会硬猜：批次跑完给「待确认表」，你一次回复编号 + 选择，再补写。

## 产出

### 打印版 Word（交付）

```
out/001_<号>_<标题>.docx
out/002_<号>_<标题>.docx
```

- 文件名前缀是全局序号（脚本 id），按 001、002… 排序；`out` 只放打印版 Word。
- 只含：标题、账号/出镜人、口播逐字稿或双人对白稿。
- 不含：对标拆解、拍摄提示、合规说明、发布包、版本记录、时间轴/分镜。
- 品牌号为双人对白稿，心悦/小冯台词加粗标出。
- 排版按老板 2026-10-20 在 001 上改定的样式：微软雅黑，标题/正文 **10.5pt（五号）**，单倍行距，正文首行缩进 32pt、段后 8pt；标题加粗、段后 10pt；账号行灰色 10.5pt、段后 22pt；A4，页边距上下 2.2cm、左右 2.4cm。
- 不再生成三平台标题/话题/封面发布包。

### 内部工作稿（不交付）

```
data/scriptgen/scripts/<YYYY-MM-DD>/<号>/SG-YYYYMMDD-NNN_<标题>.md
data/scriptgen/batches/<批次号>.md
data/scriptgen/scripts/index.md
```

内部稿包含对标结构、拍摄提示、合规自检、事实来源、版本记录；用于审核和追溯，不打印。

### 本地知识库

```
knowledge/reference/<平台>/<作者>/<作品ID>.md
```

含作品元数据、口播全文、逐句时间轴、结构拆解摘要。原始对标文案只在本地，`knowledge/` 已加入 `.gitignore`，避免进公开仓库。

### SQLite 表

`data/xmt.db` 新增：

| 表 | 内容 |
|---|---|
| `sg_reference_videos` | 对标作品元数据 |
| `sg_transcripts` | 口播转写与逐句时间轴 |
| `sg_breakdowns` | 结构拆解、账号/产品判断 |
| `sg_scripts` | 脚本主表（状态、版本、文件路径、合规结果） |
| `sg_script_versions` | 改稿历史 |
| `sg_batches` | 批次结果与待确认表 |
| `sg_usage` | RedFox 调用记录 |

## 审核与同步

状态：`待审` / `合规待修` / `已通过` / `已退回` / `已同步`。

- 生成后默认 `待审`；有高风险命中则 `合规待修`。
- 人工终审：`approve <编号...>`；批量口令由对话层调用，可一次传多个编号。
- 改稿：`revise <编号> --instruction "..."`，保留版本记录；目标时长可用「50秒」「72秒」覆盖。
- 同步：只有 `已通过` / `已同步` 能 `sync`；写入公司知识库 `marketing`，内容包括脚本 + 拆解摘要 + 方法论 + 合规自检 + 发布提示。
- 样例两条（SG-20261020-001/002）已人工通过，但**未同步公司知识库**（用户选择暂不同步）。

## 合规

自动扫描配置：`config/compliance.json`。依据《广告法》第十六条与《医疗器械广告审查办法》的保守口径：

- 不做疗效/治愈/安全保证；不提治愈率/有效率；不与其他品牌对比；不用患者/专家/医生作推荐证明；不用绝对化/最高级用语。
- 不写具体价格；不编造数字和客户故事。
- 数字类事实必须在知识库事实片段里找到来源，否则标中风险。
- 与对标原文做重合度检查：n-gram 重合率 >12% 或最长公共子串 ≥20 字，判高风险。
- 发布文案末尾固定追加免责声明；如作为医疗器械广告发布，仍需按《医疗器械广告审查办法》完成审查并标注注册证号/广告批准文号。
- 本模块是内容草稿工具，不替代法务/广告审查。

## 技术链路

```
链接
  → 短链解析（抖音）
  → RedFox：
       get_work_wide / get_work / download_douyin（抖音元数据）
       get_work_by_link（视频号元数据）
       transcript_submit + transcript_result（两平台提文案）
  → 失败兜底：RedFox 去水印下载 → ffmpeg 抽 16k 单声道 → faster-whisper medium → OpenCC 繁转简
  → 本地 SQLite + Markdown
  → DeepSeek：结构拆解 → 账号判断 → 选品匹配 → 写逐字稿 → 合规修正
  → 人工审核 → （可选）公司 KB marketing
```

- 同一链接成功转写后走缓存，不重复扣 RedFox 额度。
- 单条失败最多重试 2 次；批次预计超过 50 次计费调用时，需要 `--yes` 才继续。
- 兜底下载的视频默认用完即删（`--keep-video` 可保留）。
- 本地 Whisper 首次使用会下载 medium 模型（约 1.5GB）；有 NVIDIA GPU 会尝试 CUDA，失败自动回 CPU。

## 已知限制

- 视频号全自动依赖 RedFox；链接格式异常或接口未收录时，走 RedFox 下载 + 本地 ASR；两者都失败会在批次里明确报错，不假装成功。
- 本地 ASR 兜底代码已实现、依赖已装，但尚未用真实失败链路跑到模型下载/转写完成；首次真实兜底会触发模型下载。
- 只做文本级拆解，不抽帧、不做画面 OCR/联系表。
- Word 交付只含逐字稿/对白稿；对标拆解、拍摄提示、合规信息只保留在内部 Markdown。
- 不做自动发布，不接平台上传。
- P21 / 希维尔两个型号的对应关系和到店状态待确认。
- 公司 KB 同步只做了 dry-run 和内容结构校验，尚未真实写入；真实写入前需你明确同意。
- 医疗器械广告审查仍需人工/法务完成。

## 故障排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `未配置 COMPANY_KB_TOKEN` | 公司 KB token 缺失 | 设置用户级环境变量，重开终端 |
| 抖音元数据 3203 | 优质库未收录 | 模块自动改走广域库/下载接口；仍失败则只保留文案 |
| 提文案超时 | RedFox 排队/视频过长 | 自动转本地下载 + Whisper；也可 `--force` 重试 |
| 本地 ASR 首次很慢 | 正在下载 medium 模型 | 等下载完成；或临时改 `config/scriptgen.json` 的 model 为 `small` |
| 批次超过阈值 | 预计 >50 次计费调用 | 确认成本后加 `--yes` |
| 脚本字数偏长 | LLM 没守字数 | 模块会二次压缩；仍偏长可用 `revise --instruction "压到 50 秒"` |
| 公司 KB 写入失败 | token 权限/接口格式 | 先 `sync --dry-run` 看内容；检查 token 是否有 writer 角色 |
