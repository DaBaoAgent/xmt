# 佳康顺新媒体运营流程（高客单价医疗器械辅具版）

> 适用：电动轮椅、助行器、护理床、代步车等单价 1,000–5,500 元的康复辅具。
> 本流程替代原「低价快消式」打法，核心变化见第一章。

---

## 一、为什么流程要改：客单价决定了打法

| 维度 | 低价快消（旧假设） | 高客单辅具（实际） |
|---|---|---|
| 客单价 | 几十元 | 1,000–5,500 元 |
| 决策周期 | 秒级冲动 | 3–15 天，常需家人共同决策 |
| 购买动机 | 便宜、好看 | **安全感**：怕摔、怕买错、怕售后没人管 |
| 内容目标 | 冲点赞、涨粉 | **建立专业信任 + 抓到留资** |
| 转化路径 | 直播间秒下单 | 内容 → 私信 → 加微 → 到店/上门试车 → 成交 |

**结论：点赞和播放量不是目标，留资和到店试车才是。** 一条 50 万播放但没人加微的视频，业绩贡献是 0；
一条 3,000 播放带来 5 个加微的视频，能成交 1–2 单。所有内容决策按这个标准评判。

## 二、内容双线（2026-10 起执行）

### A 线：全实拍 —— 真人、真机、真场景

**取消纯产品展示与参数播报**；所有内容实拍，产品只做配角，使用者和场景做主角。

**主角优先级**（越靠前越可信）
1. 真实用户（含已成交客户回访）—— 最高转化
2. 员工 / 售后师傅 / 安装师傅
3. 老板、主播（人设号用）

**场景库**（优先选有「生活毛边」的）
`家里 / 小区楼道 / 菜市场 / 医院 / 公园 / 公交站 / 车后备箱 / 上下坡 / 门槛 / 电梯`

**三类选题结构**

| 类型 | 结构 | 举例 | 目的 |
|---|---|---|---|
| 用户故事 | 谁 + 什么困难 + 怎么解决 + 用后变化 | 「我妈半年没下楼了」→ 试用 → 现在每天去公园 | 情绪共鸣、信任 |
| 场景实测 | 一个硬指标 + 极限场景 | 过坎 / 爬坡 / 折叠装车 / 续航 / 刹车距 | 专业可信 |
| 专业答疑 | 提问 + 分点回答 + 避坑 | 「什么情况该买电动轮椅而不是助行器」 | 搜索长尾、决策参考 |
| **挑战式实测（优先）** | 下战书 + 极限环境 + 连载下一站 | 「质疑我们爬不了坡？直飞重庆测爬陡坡，下一站上海」 | 拉新爆发、系列追更 |

> **对标验证（2026-10 首次采集，抖音 2 个同类目号）**
> - 皮皮熊电动车旗舰店（14.9 万粉）：最高 **2,112 赞** =「质疑我们代步车爬不了坡？直飞重庆测爬陡坡，下一站上海」——
>   **挑战式实测 + 地域连载**是全类目目前最有效的形态；其次 432 赞「带老人坐飞机的适老化攻略」、31 赞「给不会开车的丈母娘安排代步车」——
>   **人情场景 + 具体身份**（丈母娘 / 父母 / 中秋）同样稳定出量。
> - 护卫神官方旗舰店（9.7 万粉）：1,255 赞为情绪文案（「观四季更迭，念朝夕温暖相伴」），攻略与测试类 20–58 赞 ——
>   情绪文案偶发出爆款但不可复制，**实测与攻略才是稳定底盘**。
> - 对照：自有内容最高 3 赞，标题多为「快速展开好操作，轻巧出行无压力」这类卖点陈述。
> - **A 线优先排产顺序**：① 挑战式实测（系列化，难度/地域递进）→ ② 人情故事（具体身份 + 节日场景）→ ③ 适配攻略 → ④ 专业答疑。

**拍摄规范（硬性）**
- 竖屏 9:16 为主，横屏 16:9 备用（视频号/公众号）
- **开头 3 秒必须出现「人 + 动作」**，禁止纯产品空镜开头
- 单镜头 ≤ 8 秒，成片 25–60 秒
- 字幕**必须全配**（目标人群有听障与老年用户），字号偏大、描边清晰
- 保留原声与环境音（车声、楼道回声），不用纯 BGM 盖掉真实感
- 每个产品至少拍：整体外观 / 折叠收纳 / 上下坡 / 过坎 / 使用者面部表情

### B 线：AI 漫剧系列 —— 低成本、可批量、系列化软植入

**定位**：填补实拍产能缺口，用连续剧形式做长期信任沉淀；**不替代实拍，做增量**。

**系列设定（一季 30 集，模板）**
- 世界观：一个固定社区 / 家庭 / 康复中心（固定场景降低生成成本）
- 固定角色 5–6 个：需要辅具的长辈 + 家属 + 社区医生/康复师 + 邻居
- 每集一个生活难题 → 引入产品 → 解决问题 → 留一个悬念

**软植入规则（关键）**
1. **产品露脸 ≤ 15% 时长**，重点是「使用场景 + 效果可见」，不做口播硬广
2. 每集**只植入 1 个卖点**（如「能折叠进后备箱」），避免卖点堆砌
3. 植入方式必须是**剧情自然结果**：人物有困难 → 产品解决了 → 镜头特写
4. 每集片尾固定一句价值观（如「让长辈自己走得动，才是最好的照护」），沉淀品牌调性
5. **画面必须有「剧情演绎」标注**（合规必需，见第七章）

**生产 SOP**
```
1. 脚本     insight/ 批量生成（一季 30 集一次性出，人工改 20%）
2. 角色定妆  lira 图像提示词 → 固定角色形象（保证跨集一致性）
3. 分镜提示词 cinedance 导演系统（镜头语言 + 运镜）
4. 生成     AutoDL H3 / Agnes 图生视频、关键帧
5. 配音     VoiceStudio（固定音色，跨集一致）或 DashScope
6. 剪辑字幕  剪映：字幕全配、片头 3 秒钩子、片尾价值观
7. 发布     三端同步（抖音 / 视频号 / 小红书），周更 2–3 集
```

## 三、平台分工（按高客单转化角色分）

| 平台 | 角色 | 主投内容 |
|---|---|---|
| 抖音 | 拉新 + 建立信任 | 实拍用户故事为主，漫剧为辅 |
| 小红书 | **决策参考**（高客单主战场） | 实拍 + 图文测评、比价、避坑 |
| 视频号 | 私域沉淀 + 老客复购 | 漫剧系列 + 客户回访，引导加微 |
| 美团 / 高德百度地图 | **到店成交** | 店铺套餐、团购券、评价维护 |
| 微信小店 / 抖店 | 承接成交 | 商品页合规化、售后说明前置 |
| 闲鱼 | 补充（类目受收紧影响） | 标题与主图合规化，规避风控 |

> 注意：8→9 月出现的渠道断档（美团 2,748 → 13.5 元）说明**到店渠道停摆会直接掉单**，
> 地图与美团在流程里不是可选动作，是固定动作。

## 四、转化链路（高客单必须留资）

```
内容（实拍/漫剧）
   ↓ 评论区 + 私信引导
加微信 / 留电话
   ↓ 需求确认（身体状况 / 预算 / 楼层 / 是否需要上门）
上门试车 / 到店体验          ← 高客单的关键成交环节
   ↓
成交（含租赁 / 分期）
   ↓ 售后回访（7 天 / 30 天）
复购 & 转介绍（老带新返券）
```

**每条内容必须带一个留资钩子**（固定三选一）
- 免费上门试车 / 体验
- 以旧换新免费评估
- 适老化改造评估（楼道、卫生间、门槛）

## 六、KPI（已换口径）

**主 KPI（考核这些）**
- 留资数（私信 + 加微 + 留电话）
- 到店 / 上门试车数
- 成交单数与客单价（含租赁）

**副 KPI（参考，不考核）**
- 完播率、互动率、粉丝增长

**明确不做**：为点赞做无留资钩子的纯流量内容。

## 七、合规红线（医疗器械，必须逐条自检）

1. **禁止疗效承诺**：不得出现「治好 / 康复 / 代替治疗 / 不用去医院」等表述
2. **禁止极限词**：最好 / 最快 / 第一 / 国家级 / 100%
3. **禁止虚构数据**：不得编造「xx% 用户有效」这类统计
4. **AI 漫剧必须标注**「剧情演绎，非医疗建议」（画面常驻角标）
5. **资质前置**：抖音等平台销售轮椅类需二类医疗器械资质，商品页需展示
6. **租赁也要合规**：押金、租期、归还条件写清（避免纠纷，9 月押金池 3,300 元全额归还=可宣传的信任点）

> 现有词库与自动替换见 `insight/copy.py` 的 `_scrub` / 合规自检逻辑；漫剧脚本同样过一遍。

## 八、落地检查清单（每次发布前 30 秒自检）

- [ ] 开头 3 秒有「人 + 动作」？
- [ ] 产品占比 < 30%（漫剧 < 15%）？
- [ ] 有留资钩子（上门试车 / 以旧换新 / 适老化评估）？
- [ ] 字幕全配、字号偏大？
- [ ] 无疗效承诺、无极限词、无编造数据？
- [ ] 漫剧有「剧情演绎」标注？
- [ ] 发布后是否登记到留资追踪表？
