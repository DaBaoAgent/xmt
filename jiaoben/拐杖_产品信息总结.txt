一、产品线概述
================================================================================
1. 品牌：佳康顺（英文标识 UNQ / UNQaid；详情页出现 "UNQ" 与 "nip-cane series 03"
   双标识，标注 Designed in New Zealand / Made in China）
2. 品类：老人助行拐杖（手杖 / 肘拐 / 折叠拐 / 带灯拐 / 多脚底座拐）
3. 材质分档（由低到高）：
   - 6061 铝合金（GB 系列手杖、铝合金多脚底座拐杖）
   - 航空钛合金 / 铝合金复合（HH-109）
   - 水转印仿碳（HH-101-NT 碳转印版，表面仿碳纹理，非全碳）
   - 复合碳纤维（HH-101-NT 碳纤维版）
   - 全碳纤维（XW-910L 超轻款、HH-101-TZ 肘拐）
4. 结构形态：
   - 直柄手杖（单脚 / 四角 / 万向多脚底座可换）
   - 肘拐（HH-101-TZ，U 型托 + 前臂支撑）
   - 折叠款（GB-802 / GB-819 / 碳纤维系列、HH-101-TZ）
   - 双形态（HH-109 手杖 T 型握把 ↔ 垂直握把 90° 旋转切换）
5. 功能配置分档：普通款 / 带灯款 / 带灯+SOS 报警+FM 收音机款 / 辅助起身款 /
   礼盒款（送礼场景）
6. 核心目标人群：65 岁以上腿脚无力、平衡差、上下楼乏力、夜间出行需求的老人；
   以及术后康复、登山辅助人群。

六、使用与安全要点（详情页归纳）
================================================================================
1. 高度调节：按住弹珠 / 按压卡扣调到合适档位，务必听到"咔"声并锁紧金属锁箍，
   调节后试压确认不晃动；标准高度为站立时手腕水平线附近。
2. 底座选择：行走较稳选单脚；需要更大支撑面选小四脚；平衡差、康复期选大四脚
   或万向底座。
3. 折叠式（GB-802/GB-819/碳纤维/HH-101-TZ）：先收至最短节再折叠，避免
   锁扣受力变形；折叠后勿作支撑使用。
4. 照明 / 报警款：LR44 纽扣电池款需注意电池仓防水；内置锂电款长期不用应
   定期补电。
5. 脚垫磨损（出现露底、硬化、开裂）必须更换后再使用，橡胶脚垫失效是老人
   跌倒的主要诱因之一。
6. 承重使用不超过标称值（GB-819 100kg、GB-802/GB-801 113kg、HH-101-NT 100kg）。
7. 雨雪、油污瓷砖地面摩擦系数下降，需减速并在干燥处行走。
