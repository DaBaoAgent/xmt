## 一、项目整体定位

### 1.1 业务本质
这是一套**佳康顺新媒体业务一体化数据工具**，集「账号矩阵数据采集 + 对标/选题分析 + 销售租赁报表 + 汇报材料生成」于一体，全部本地运行、SQLite 存储、单文件 HTML 看板。

### 1.2 核心商业模式
- **客单价区间**：1,000–5,500 元（高客单价医疗器械辅具）
- **决策周期**：3–15 天，常需家人共同决策
- **购买动机**：安全感 —— 怕摔、怕买错、怕售后没人管
- **数据口径**：有押金 = 租赁订单，无押金 = 销售订单

### 1.3 运营主线（2026-10 起）
**内容目标从「冲点赞」转为「建立专业信任 + 抓到留资」**
- A 线（主力）：全实拍 —— 真人、真机、真场景，一物一故事
- B 线（增量）：AI 漫剧系列软植入 —— 一季 30 集、固定世界观、产品露脸 ≤15%
- KPI：留资数、到店试车数、成交单数（点赞与播放量只作参考）

## 四、内容生产体系

### 4.1 翔哥口播风格（已深度拆解）

**6 种标题公式**：
1. 疑问+数字承诺：「[痛点疑问] + [权威身份] + [数字] + [承诺]」
2. 警告+反常识：「[反常识断言] + [品类] + [数字] + [坑/风险]」
3. 对比选择式：「[A] 和 [B]，[人群] 该怎么选？」
4. 清单口诀式：「[购买场景] + [身份否定] + [行动指令]」
5. 教学干货式：「[恐惧痛点] + [时间承诺] + [结果承诺]」
6. 揭秘式：「[品类] 的 [隐藏技能/秘密]」

**5 种开头钩子**：
1. 痛点共鸣提问：「很多朋友问我...」
2. 反常识否定：「错！...」
3. 数字冲击：「90%的人都选错了」
4. 后果警告：「选错了不仅费钱，更是安全的事」
5. 时间承诺：「今天我用一分钟，给你讲透」

**4 种正文骨架**：
- 编号分点式（科普/决策类）
- 对比决策式（选A还是选B）
- 避坑清单式（水太深/买错系列）
- 教学步骤式（怎么用/怎么选）

**核心手法**：专业词 + 大白话翻译、给功能起外号、精确数字建立信任、短句节奏、引号强调关键词、本质升华句

**固定收尾**：「关注翔哥，了解更多辅具知识」（100%出现）

### 4.2 脚本生产 SOP（优化版）

**五步流程**：
1. 选风格模板（避坑/痛点/反常识/对比/案例/拆解/教学 7 种）
2. 写标题（套用翔哥 6 种公式）
3. 写开头钩子（前 3 秒定生死）
4. 写 4 分镜内容（25-30 秒，每个分镜 7 秒）
5. 自检（交付前必过）

**4 分镜结构**：
| 分镜 | 时长 | 内容要求 |
|---|---|---|
| 镜1 | 0-7s | 钩子+痛点 |
| 镜2 | 7-14s | 产品展示+核心卖点1（植入具体参数） |
| 镜3 | 14-21s | 产品展示+核心卖点2（植入具体参数） |
| 镜4 | 21-28s | 总结+行动暗示（不要结尾升华） |

**硬性要求**：每条至少植入 2 个具体参数、口语化、无结尾升华、无敏感词

### 4.3 存量脚本资产
- `jiaoben/6款产品_单人口播脚本24套_全新版`（NIP/朋友2/小福车/P10/F2Q/A3）

## 五、合规红线（医疗器械行业）

### 5.1 绝对禁止
1. **疗效承诺**：不得出现「治好/康复/代替治疗/不用去医院」
2. **极限词**：最好/最快/第一/国家级/100%
3. **虚构数据**：不得编造「xx% 用户有效」
4. **价格词**：稿里不写具体价格

### 5.2 手动款产品专属禁令
手动款（助行器/手动轮椅/拐杖/骨折车）稿里**绝对不能出现**：
电机、电池、摇杆、电磁刹车、瓦、AH、锂电、续航、遥控

### 5.3 经销品牌专属规则
- 博爱方特/新芝是经销品牌，**不写「佳康顺17年匠心工厂直营」**
- 博爱方特背书：「昆山工厂、年出口」
- 新芝背书：「陆鸿（2022感动中国人物）自己在坐轮椅、工厂在苏州吴江同里」
- 名人只陈述事实，不写「名人背书/推荐」

## 七、关键洞察与待优化点

### 7.1 核心优势
1. **产品矩阵完整**：从几百元拐杖到五千元电动轮椅全覆盖，助行器/手动轮椅/电动轮椅/代步车/骨折康复车全品类
2. **双品牌互补**：佳康顺自有性价比 + 博爱方特/新芝中高端经销，高低搭配
3. **翔哥口播风格已沉淀**：6种标题公式+5种钩子+4种骨架+3套万能模板，可批量复制
4. **合规体系完善**：产品参数档案+串参高危点+手动款禁词表，从源头避免翻车
5. **数据工具链成熟**：从采集到分析到出稿到报表，全流程自动化

### 7.2 待优化点
1. **自有账号粉丝量偏低**：除翔哥小红书2.8万粉外，其他号均在几千粉级别，与对标号（皮皮熊14.9万粉、护卫神9.7万粉）差距明显
2. **内容形态需升级**：对标验证显示「挑战式实测+地域连载」是全类目最有效形态（皮皮熊最高2112赞），自有内容目前多为卖点陈述
3. **留资转化链路待打通**：KPI已从点赞转为留资，但内容中的留资钩子是否到位、转化数据是否追踪，需持续复盘
4. **P11/希维尔参数档案缺失**：两个阳光展厅确定款的数字参数尚未建立，写稿受限
5. **B线AI漫剧尚未规模化**：目前以A线实拍为主，B线漫剧作为增量产能尚未充分释放
