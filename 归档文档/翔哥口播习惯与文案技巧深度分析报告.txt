一、IP人设与视觉识别
====================

1.1 人物定位
- 身份：佳康顺工厂从业者 / 康复辅具专家 / "轮椅侠翔哥"
- 着装：蓝灰拼色工服（佳康顺logo），戴眼镜
- 场景：工厂车间、零件墙、产品展厅、办公室
- 背书："康复师告诉你"、"我是翔哥"、"轮椅侠翔哥"
- 人设关键词：专业、实在、工厂直出、避坑达人、为老人着想

1.2 视觉识别系统
- 封面统一竖版9:16
- 人物抠图+白边描边，突出主体
- 背景虚化（工厂/车间/产品）
- 标题大字叠加，红黄为主色调
- 部分封面有"轮椅侠翔哥"书法牌匾背景，强化IP记忆

1.3 口播节奏特征
- 语速中等偏快，信息密度高
- 善用停顿制造强调（"错！"、"千万不能买"）
- 数字密集出现，增强专业感
- 每段控制在30-60秒，单条视频1-3分钟


二、封面标题公式
================

2.1 四大标题类型

类型一：警告命令式（最高频）
公式：[产品] + 别[动词]！+ [利益承诺]
案例：
- "选轮椅别瞎买！记住这三点，少走90%弯路"
- "碳钢轮椅别乱买 选对才不花冤枉钱"
- "铁的轮椅也会断哦，买碳钢轮椅别光图便宜"
- "拐杖买错等于白买！这3个坑，老人最容易踩"
特征：感叹号+否定词+数字承诺，制造紧迫感

类型二：避坑指南式
公式：[产品] + 避坑指南 / 水太深 + [具体利益点]
案例：
- "电动轮椅避坑指南 真假碳纤维一眼分辨"
- "碳纤维轮椅水太深！一千和一万的差在哪？"
特征："避坑"、"水太深"关键词，激发好奇心

类型三：疑问选择式
公式：[A]还是[B]？+ [人群]该如何选择
案例：
- "老人拐杖要怎么选"
- "电动轮椅和老年代步车，老年人该如何选择？"
- "手动轮椅和电动轮椅，到底选哪个合适？90%的人都选错了"
特征：直接抛出选择难题，精准命中决策焦虑

类型四：悬念揭秘式
公式：[反常识陈述] + [揭秘承诺]
案例：
- "推了这么多年轮椅，今天才知道原来有个'隐藏开关'"
- "手动轮椅的隐藏技能"
特征："隐藏"、"才知道"、"揭秘"，制造信息差

2.2 标题配色规律
- 主标题：黄色粗体（最高频）或红色粗体
- 副标题：粉色/白色/红色
- 关键词高亮：用不同颜色区分核心词
- 字号：主标题占画面1/3以上，确保缩略图可读


三、开头钩子技巧（前3秒定生死）
================================

3.1 六大钩子模式

模式一：反常识纠正型
结构：大众误区 + "错！" + 正确观点
案例：
- "很多人觉得，坐轮椅就是'认输了'，是最后的选择。错！从康复医学看，轮椅不是不行的标志..."
- "经常有老年朋友问我，电动轮椅和老年代步车长得很像，该如何选择才对？选错了不仅花错钱，更是安全和自由的事。"
效果：打破固有认知，制造"原来我错了"的冲击

模式二：痛点提问型
结构："很多朋友问我..." + 具体痛点
案例：
- "很多朋友经常会问我：家里的老人，到底什么时候该用轮椅？"
- "经常有老年朋友问我，电动轮椅和老年代步车长得很像，该如何选择才对？"
效果：代入感强，让目标用户觉得"说的就是我"

模式三：数字承诺型
结构："X分钟/秒" + "讲透/教会/说清" + 具体内容
案例：
- "今天我用一分钟，给你讲透"
- "30秒教会你四轮带刹车助行器的正确用法"
- "二分钟给您说透"
效果：降低观看门槛，承诺明确收益

模式四：悬念揭秘型
结构："推了这么多年...今天才知道..." + "隐藏开关/技能"
案例：
- "推了这么多年轮椅，今天才知道原来有个'隐藏开关'！轻轻一弄，上个小坎、过个门框，立马省力一大半"
效果：制造信息差，激发"我也不知道"的好奇心

模式五：警告恐吓型
结构：[产品] + "也会[严重后果]" + "别光图便宜"
案例：
- "铁的轮椅也会断哦，买碳钢轮椅别光图便宜，这几个坑，商家绝不会主动告诉你"
- "碳纤维轮椅水太深！一千和一万的差在哪？"
效果：恐惧驱动，"商家不会告诉你"增强信任

模式六：身份背书型
结构："康复师告诉你" + 三个黄金信号
案例：
- "老年人什么时候需要坐轮椅了？康复师告诉你三个黄金信号"
效果：专业身份背书，增强可信度

3.2 钩子共性规律
- 必须在第一句出现"你"或"老人"或"朋友"，建立对话感
- 必须包含一个具体数字（3个坑、一分钟、90%）
- 必须制造情绪（焦虑、好奇、恐惧、恍然大悟）
- 绝不铺垫，直接进入主题


四、正文结构模板
================

4.1 四点式结构（最高频）

结构：总起 → 第一点 → 第二点 → 第三点 → 总结
适用：选购指南、避坑科普、信号判断

案例骨架（什么时候坐轮椅）：
1. 总起：很多人觉得坐轮椅=认输，错！轮椅是战略工具
2. 第一信号：行走效率和安全性崩塌（解释+后果）
3. 第二信号：疼痛成为出行主宰（解释+恶性循环）
4. 第三信号：心肺功能发出警报（解释+危险）
5. 总结：不是"完全不能走"，而是"安全无痛高效行走能力丧失"

4.2 对比决策式

结构：提出选择难题 → A选项详解 → B选项详解 → 决策标准 → 警告
适用：二选一决策类（手动vs电动、轮椅vs代步车）

案例骨架（手动vs电动）：
1. 开头：不是二选一，是"功能匹配题"
2. 第一步：评估核心能力（上肢功能+认知）
3. 第二步：明确核心场景（距离+环境）
4. 第三步：考虑隐藏成本（不仅是钱）
5. 一句话总结：上肢有力选手动，上肢乏力选电动
6. 最理想方案：电动为主，手动为辅

4.3 避坑清单式

结构：产品引入 → 第一坑 → 第二坑 → 第三坑 → 避坑方法
适用：材质避坑、选购陷阱

案例骨架（碳钢轮椅避坑）：
1. 引入：碳钢便宜但不等于划算
2. 第一坑：重量虚标（怎么查+判断标准）
3. 第二坑：焊接和防锈是隐形杀手（看什么+后果）
4. 第三坑：底盘和轴距偷尺寸（怎么测+危险）
5. 记住：图结实性价比，但安全是底线

4.4 操作教学式

结构：痛点引入 → 用前检查 → 操作步骤 → 刹车使用 → 注意事项
适用：产品使用方法、技巧教学

案例骨架（助行器使用）：
1. 引入：买了不敢用？怕摔？30秒教会
2. 一、用前先"体检"（3个检查点）
3. 二、行走操作（启动+推行+节奏）
4. 三、刹车使用（行驶+静止+座椅）
5. 四、注意事项（3个坑）
6. 结尾：转发给需要的人

4.5 结构共性规律
- 所有正文都用"第一/第二/第三"或"一/二/三/四"编号
- 每个点都有"小标题+解释+具体建议"三层
- 每个点控制在3-5句话
- 编号之间有自然过渡（"第二个信号"、"接下来"）
- 必须有一个"总结/一句话记住"收束


五、语言风格特征
================

5.1 口语化表达
- 不用书面语，全用大白话
- "讲透"、"说透"、"聊透"代替"分析"
- "别瞎买"、"别乱买"、"别光图便宜"
- "立马省力一大半"、"憋得脸红脖子粗"
- "老伙计"、"神操作"、"小白"

5.2 短句节奏
- 单句不超过20字
- 大量使用逗号断句
- 关键判断单独成句："错！"、"千万不能买"、"绝对不行"
- 案例："记住，买碳钢轮椅，图的是结实和性价比，但安全是底线。"

5.3 数字密集
- 几乎每段都有数字
- 具体参数："20-30度"、"至少40厘米"、"15公斤以下"
- 比例数字："90%的人"、"少走90%弯路"
- 时间数字："一分钟"、"30秒"、"三年"
- 效果：增强专业感和可信度

5.4 对话感营造
- 高频使用"你"、"您"、"咱们"
- 设问句："怎么办？"、"如何选择？"
- 直接指令："你就问他这几个问题"、"记住"
- 称呼："老年朋友"、"家里的老人"、"小伙伴"

5.5 情绪词库
- 焦虑类："水太深"、"坑"、"白买"、"冤枉钱"
- 安全类："安全第一"、"防跌倒"、"稳稳停下"
- 利益类："省力"、"秒上手"、"实用性拉满"
- 信任类："商家绝不会主动告诉你"、"康复师告诉你"


六、专业表达技巧
================

6.1 术语转化为日常比喻

| 专业概念 | 翔哥式表达 | 效果 |
|---------|-----------|------|
| 轮椅代偿功能 | "能量管理器"、"防跌倒装置" | 把工具变成"保护者" |
| 疼痛限制活动 | "无痛出行工具" | 直接点出核心价值 |
| 心肺功能不足 | "移动供氧站"、"心脏减负器" | 比喻生动，一听就懂 |
| 电动轮椅定位 | "身体功能的延伸" | 升维表达 |
| 代步车定位 | "简化版的微型电动车" | 降维类比 |
| 碳纤维贴膜 | "贴膜碳纤维"、"只改外观，不增强度" | 一针见血 |

6.2 "是什么+为什么+怎么办"三段式
每个专业点都按这个逻辑展开：
- 是什么：定义概念（"手动轮椅是上肢驱动的工具"）
- 为什么：解释原理（"要求足够的上肢力量、协调性和耐力"）
- 怎么办：给出行动（"能持续推行至少15分钟"）

6.3 对比锚定法
- 永远给参照物："和铝合金款对比"、"如果重量相差不到10公斤"
- 给判断标准："轴距至少要有40厘米"、"全碳纤维能做到15公斤甚至13公斤以下"
- 给价格锚点："正宗的全碳纤维电动轮椅，售价至少都要大几千"

6.4 场景化描述
- 不抽象说"方便转移"，而说"从轮椅上转移到床上或者吃饭的地方、洗澡的地方"
- 不说"续航长"，而说"每天去较远的公园、超市"
- 不说"制动好"，而说"想停车时一拉手刹，立马稳稳停下，不会乱跑"


七、结尾转化设计
================

7.1 四种结尾模板

模板一：一句话总结+关注引导
"一句话总结：上肢有力、活动范围小、追求灵活康复——选手动。上肢乏力、渴望远行、认知手控达标——选电动。关注翔哥，了解更多辅具知识。"

模板二：金句收束+身份强化
"记住，买碳纤维不仅仅是买花纹，是买它轻如塑料、强过钢铁的物理性能。"

模板三：互动引导+下期预告
"觉得有用的，给翔哥点个赞，转发给身边需要的人。你还想知道轮椅的哪些'神操作'？评论区告诉我，下期接着聊！"

模板四：转发呼吁+情感共鸣
"赶紧转发给家里需要的人，一起守护出行安全～"

7.2 结尾共性
- 必须有"关注翔哥，了解更多辅具知识"（固定slogan）
- 必须有一个可记忆的金句或口诀
- 鼓励转发（"转发给身边需要的人"）
- 部分有互动引导（评论区提问）
- 绝不突然结束，必须有收束感


八、选题策略矩阵
================

8.1 四大选题方向

方向一：选购决策类（占比最高）
- 轮椅怎么选、手动还是电动、轮椅还是代步车
- 老年代步车选购、拐杖怎么选、助行器怎么选
- 核心：解决"买哪个"的决策焦虑

方向二：避坑科普类
- 碳钢轮椅避坑、碳纤维真假辨别
- 拐杖3个坑、充电器误区、电池选购
- 核心："商家不会告诉你"的信息差

方向三：使用技巧类
- 手动轮椅隐藏技能、助行器正确用法
- 轮椅扶手选择、坐垫选择、脚踏选择
- 核心："买了不会用"的实操指导

方向四：认知纠正类
- 什么时候该坐轮椅、为什么要用辅具
- 久坐不累、定改制轮椅是什么
- 核心：打破"坐轮椅=认输"的偏见

8.2 选题命名规律
- 文件名即选题："10轮椅怎么选"、"23铁的轮椅也会断哦"
- 编号连续，从1到48，持续更新
- 标题自带冲突点："也会断"、"水太深"、"买错等于白买"
- 高频复用品类词：轮椅、拐杖、助行器、代步车、电机、电池、控制器

8.3 内容进阶轨迹
- 早期（1-10期）：基础品类科普（拐杖、轮椅、助行器）
- 中期（11-30期）：零部件深度（轮子、电机、电池、控制器、坐垫、脚踏）
- 近期（31-48期）：高阶主题（定改制、老博会、久坐不累、爆款打造）
- 规律：从"是什么"到"怎么选"到"避坑"到"高阶玩法"，逐步深化

十、优化建议

10.1 已做得好的方面（继续保持）
- 封面标题警告式+数字承诺，点击率有保障
- 开头3秒必有钩子，完播率基础好
- 正文编号结构清晰，信息密度高
- 专业术语比喻化，降低理解门槛
- 工厂场景+工服人设，信任背书强
- 结尾固定slogan，品牌记忆点清晰

10.2 可优化方向

1. 开头钩子可更极致
- 当前钩子多为"很多人问我"，可增加"你是不是也..."的直接提问
- 可尝试"昨天有个粉丝..."的故事型开头，增强代入
- 数字可更具体："90%的人都选错了"→"10个家庭8个买错"

2. 正文可增加案例
- 当前以原理讲解为主，可加入真实用户故事
- 比如"上周有个阿姨买了碳钢轮椅，搬不动..."
- 案例比原理更有传播力

3. 结尾互动可强化
- 当前"评论区告诉我"出现频率低
- 可固定每期结尾一个选择题："你家是手动还是电动？评论区打1或2"
- 互动率直接影响推流

4. 封面可增加人物表情
- 当前封面人物多为正面微笑，可增加惊讶、认真、指向产品等表情
- 表情与标题情绪一致（警告标题配严肃表情）

5. 选题可系列化
- 当前选题较散，可打造"翔哥避坑系列"、"翔哥一分钟系列"
- 系列化有助于用户追更和账号标签强化

6. 口播节奏可增加停顿
- 当前信息密度高，可在关键结论后留白1秒
- 比如"错！"之后停0.5秒，增强冲击力
- 数字前后停顿，强化记忆
