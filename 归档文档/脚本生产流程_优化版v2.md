> 更新时间：2026-10-23
> 基于：对标验证（皮皮熊2112赞挑战式实测）+ 翔哥口播风格深度拆解 + 高客单运营流程 + 产品参数档案

## 一、流程总览（两条出稿路线）

| 路线 | 适用场景 | 入口 | 产出速度 |
|---|---|---|---|
| **路线A：对标贴改写** | 有对标链接、想学某个账号的表达 | 发对标链接 → scriptgen add | 中（需抓对标+转写） |
| **路线B：展厅分镜直出** | 无对标、产品在展厅、批量出稿 | 选产品+选风格 → make_showroom_scripts | 快（4套/产品） |

两条路线共用同套：产品参数档案、人设卡、合规扫描、一键收尾、质量检查。

## 二、路线A：对标贴改写（优化点标注 ★）

### 第 0 步：明确四个输入（原有）
对标链接 / 账号 / 产品 / 数量风格 —— 不变。

### 第 1 步：抓对标账号（原有）
短链解析 → profile → items —— 不变。

**★ 新增：选题形态判断**
挑代表作时，先判断它属于哪种形态，按效果排序：
1. **挑战式实测**（最优）：下战书 + 极限场景 + 连载预告 —— 皮皮熊最高2112赞的形态
2. **人情故事**（次优）：具体身份（丈母娘/父母/中秋）+ 真实场景
3. **适配攻略**（稳定）：避坑/选购指南/对比选择
4. **产品展示**（最弱）：纯参数播报 —— 自有内容目前多是这种，最高才3赞

> 挑对标时优先挑1、2类，少挑4类。

### 第 2 步：抓视频转写（原有）
不变。

### 第 3 步：写账号分析（原有）
五节：基本面/逐句转写/风格拆解/合规雷区/套用建议 —— 不变。

**★ 新增：风格骨架归类**
分析完必须标注这条对标用了哪种骨架（对应翔哥4种骨架）：
- A 编号分点式（科普/决策）
- B 对比决策式（选A选B）
- C 避坑清单式（水太深/买错）
- D 教学步骤式（怎么用）

骨架决定了我们写稿时套用哪个模板（见第6步）。

### 第 4 步：查产品参数（原有）
先查 `docs/产品参数档案.md`，没有再查知识库 —— 不变。

**★ 新增：串参高危点自查**
写之前先过一遍档案里的「跨产品串参高危点表」，确认本次要写的型号，把它的专属参数单独列出来，别和同品类其他型号混。

**★ 新增：经销品牌身份确认**
如果是博爱方特/新芝，先确认：
- 不写「佳康顺17年匠心工厂直营」
- 博爱方特背书 = 昆山工厂/出口欧美
- 新芝背书 = 陆鸿（感动中国人物）/苏州吴江同里

### 第 5 步：查人设卡（原有）
三号人设：oral / brand / personal —— 不变。

**★ 新增：CTA强制对应**
| 号 | 结尾必须引导 | 不能出现 |
|---|---|---|
| oral 口播号 | 关注翔哥 + 转给他需要的人 | 不提上门试车/加微 |
| brand 品牌号 | 到店试车 / 展厅体验 | 不说「关注我」 |
| personal 个人号 | 来展厅看看 / 工厂店直租 | 不说专业术语堆参数 |

### 第 6 步：写稿（核心优化区）

#### 6.1 先定骨架模板（★ 新增，强制）
根据第3步判断的对标骨架，选对应模板写：

**模板1：避坑科普式（最容易出爆款）**
```
标题：[品类]水太深/买错等于白买！[数字]个坑，[人群]最容易踩
开头：我们买[品类]，图的就是[核心需求]。但市面上[乱象]，这里边的坑，我今天给您聊聊。
正文：
  第一坑：[坑名] → 原理 → 怎么识别
  第二坑：[坑名] → 原理 → 怎么识别
  第三坑：[坑名] → 原理 → 怎么识别
避坑总结：一看[标准1]，二看[标准2]
金句收尾：记住，买[品类]不仅仅是买[表面]，是买[本质价值]。
```

**模板2：对比决策式**
```
标题：[A]和[B]，[人群]该怎么选？[数字]%的人都选错了
开头：经常有[人群]问我，[A]和[B]长得很像，该怎么选？选错了不仅[后果1]，更是[后果2]。
正文：
  根本区别，在于[核心差异]。
  [A]：目标→参数→本质是[比喻]→适合[场景]→解决[问题]
  [B]：目标→参数→本质是[比喻]→适合[场景]→解决[问题]
一句话总结：[条件1]选A，[条件2]选B。最理想是[组合方案]。
```

**模板3：时机/认知科普式**
```
标题：[疑问]？[权威身份]告诉你[数字]个[信号]
开头：很多人觉得[错误认知]。错！从[专业角度]看，[正确认知]。出现以下[数字]个信号，就必须严肃考虑。
正文：
  第一个信号：[表现] → [后果] → 产品是[比喻]，解决[问题]
  第二个信号：[表现] → [后果] → 产品是[比喻]，解决[问题]
  第三个信号：[表现] → [后果] → 产品是[比喻]，解决[问题]
总结：用[产品]的最佳时机，不是[极端情况]，而是[正确标准]的时候。
```

#### 6.2 开头钩子（★ 新增，5选1）
前3秒必须用以下钩子之一，不能平铺直叙：
1. **痛点共鸣提问**：「很多朋友问我：家里老人到底什么时候该用轮椅？」
2. **反常识否定**：「很多人觉得坐轮椅就是认输了？错！」
3. **数字冲击**：「90%的人买轮椅都买错了」
4. **后果警告**：「选错轮椅不仅费钱，更是关系到安全」
5. **时间承诺**：「今天我用一分钟，给你讲透」

#### 6.3 内容要求（原有+新增）
- 骨架照搬对标、词换近义（原有）
- 每篇至少植入2个具体参数（原有）
- 口语化，像跟朋友聊天（原有）
- **★ 新增：开头3秒必须出现「人+动作」**（拍摄提示里标注，不能纯产品空镜开头）
- **★ 新增：场景指定**（写清楚在哪拍：家里/楼道/菜市场/公园/车后备箱/上下坡/门槛/电梯）
- **★ 新增：留资钩子（固定三选一，强制）**：
  - 免费上门试车 / 到店体验
  - 以旧换新免费评估
  - 适老化改造评估（楼道/卫生间/门槛）
- **★ 新增：禁止结尾升华**（「愿天下老人都能...」这种不要，要口语化收尾）
- **★ 新增：手动款禁词扫描**（电机/电池/摇杆/电磁刹车/瓦/续航/遥控 —— 出现即删）

#### 6.4 批量生产角度规划（★ 新增，前置）
同一产品出多篇时，先规划好4种角度不重复：
1. 痛点避坑向
2. 场景故事向
3. 功能参数向
4. 反差/黑科技向

写第2篇起先跑 `--angles` 查已用角度（原有），但应该在选题阶段就排好，不要写到一半才发现撞角度。

### 第 7 步：一键收尾（原有）
`finish_script.py` 自动完成渲染+接序号+ORDER+刷产出+质量检查 —— 不变。

**★ 新增：finish_script 应增加的检查项**
- [ ] 手动款产品是否误写电动词（按产品参数档案的禁词表扫）
- [ ] 是否有留资钩子（三选一是否出现）
- [ ] 开头是否符合5种钩子之一
- [ ] 结尾是否有升华套路（「愿...」「让每一位...」这类）

### 第 8 步：质量自查（原有+扩充）
原有8项 + 新增：
- [ ] 开头3秒是否有「人+动作」拍摄提示
- [ ] 是否指定了拍摄场景
- [ ] 是否带了留资钩子
- [ ] 结尾是否口语化（无升华套路）
- [ ] 手动款无电动词（按型号扫）
- [ ] 经销品牌无佳康顺背书

### 第 9 步：归档（原有）
不变。

## 三、路线B：展厅分镜直出（优化点标注 ★）

### 现有结构（4分镜×7秒）
| 分镜 | 时长 | 内容 |
|---|---|---|
| 镜1 | 0-7s | 钩子+痛点 |
| 镜2 | 7-14s | 产品+卖点1 |
| 镜3 | 14-21s | 产品+卖点2 |
| 镜4 | 21-28s | 总结+行动暗示 |

### ★ 优化：每个分镜增加「拍摄指令」列
| 分镜 | 时长 | 口播内容 | 拍摄指令（人+动作） |
|---|---|---|---|
| 镜1 | 0-7s | 钩子台词 | 谁出镜+在什么场景+做什么动作（如：小冯站在展厅门口，推着车迎向镜头） |
| 镜2 | 7-14s | 卖点1 | 特写哪个部位+怎么操作（如：手指指向折叠按钮，演示一拉就折） |
| 镜3 | 14-21s | 卖点2 | 实测什么场景（如：把车放进SUV后备箱，关上门） |
| 镜4 | 21-28s | 收尾+留资 | 人物表情+结束语（如：小冯靠在车上，笑着说「想试的来展厅」） |

### ★ 优化：一产品4套角度分配（原有+细化）
| 套号 | 角度类型 | 适用风格 |
|---|---|---|
| 第1套 | 痛点避坑向 | 避坑指南风 / 踩坑吐槽 |
| 第2套 | 场景口碑向 | 亲戚口碑风 / 用户视角 |
| 第3套 | 功能参数向 | 功能拆解风 / 参数拆解 |
| 第4套 | 反差/黑科技向 | 反常识风 / 黑科技风 |

### ★ 优化：留资钩子写入镜4
每套稿的镜4结尾必须带留资钩子（三选一），不能只说「喜欢就点个赞」。

## 四、B线：AI漫剧脚本（★ 新增，目前缺失）

运营流程里有B线漫剧，但scriptgen模块还没覆盖，补充规范：

### 漫剧脚本结构（每集28-35秒）
| 段 | 时长 | 内容 |
|---|---|---|
| 开场钩子 | 0-5s | 生活难题出现（如：奶奶出门被门槛绊倒） |
| 剧情发展 | 5-20s | 家人讨论+想到办法（产品自然出现） |
| 产品解决 | 20-28s | 产品使用场景特写（≤15%时长），只植入1个卖点 |
| 结尾悬念 | 28-35s | 留一个钩子（如：「第二天奶奶又遇到了新问题...」） |

### 漫剧合规要求
- 画面常驻「剧情演绎，非医疗建议」角标
- 产品露脸≤15%时长
- 每集只植入1个卖点
- 不做口播硬广，剧情自然带出

## 五、写稿硬参数速查（汇总版）

| 项 | 口径 |
|---|---|
| **口播号时长** | 60-90s / 260-400字 |
| **品牌号时长** | 30-45s / 150-240字（可单人出镜） |
| **个人号时长** | 45-60s / 200-280字 |
| **对标贴改写比例** | 我方时长 = 对标时长 × 0.8-1.3倍 |
| **每篇参数植入** | 至少2个具体参数（型号/重量/尺寸/材质） |
| **开头钩子** | 5种之一（痛点提问/反常识否定/数字冲击/后果警告/时间承诺） |
| **标题公式** | 6种之一（疑问+数字/警告+反常识/对比选择/清单口诀/教学干货/揭秘） |
| **留资钩子** | 三选一（上门试车/以旧换新评估/适老化评估），每条必带 |
| **结尾要求** | 口语化，无升华套路 |
| **手动款禁词** | 电机/电池/摇杆/电磁刹车/瓦/AH/锂电/续航/遥控 |
| **经销品牌规则** | 博爱方特/新芝不写「佳康顺17年匠心」背书 |
| **批量角度** | 同产品4套角度不重复（痛点/场景/参数/反差） |

## 六、选题优先级（★ 新增，基于对标验证）

排产时按这个顺序选选题：
1. **挑战式实测系列**（拉新爆发、可连载）—— 如「质疑我们爬不了坡？去重庆测」
2. **人情故事**（稳定出量、有共鸣）—— 具体身份+节日场景
3. **适配攻略/避坑**（搜索长尾、决策参考）—— 高客单用户最爱搜的
4. **产品功能展示**（稳定但流量低）—— 保底产能

> 自有内容目前最高才3赞，原因是多做了第4类、少做了第1、2类。后续把第1、2类占比提到60%以上。
