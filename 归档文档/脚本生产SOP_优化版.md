## 一、脚本生产五步流程

### 第1步：选风格模板（先定套路再写内容）
每条脚本必须从以下风格中选一种，不能混搭：

| 风格类型 | 适用产品 | 核心特点 |
|---|---|---|
| 避坑指南风 | 全品类 | 警告式开头+踩坑案例+正确做法 |
| 痛点共鸣风 | 全品类 | "很多人问我..."开头+用户痛点+解决方案 |
| 反常识风 | 高端/新品 | "你以为...其实错了"开头+认知颠覆 |
| 对比选择风 | 多品类对比 | "A和B到底选哪个？"开头+优缺点对比 |
| 用户案例风 | 全品类 | "我舅/我妈/昨天有个阿姨..."开头+真实场景 |
| 产品拆解风 | 高端款 | 逐个讲参数+为什么贵/好 |
| 教学干货风 | 操作类产品 | "30秒教会你..."开头+步骤演示 |

### 第2步：写标题（用翔哥6种公式）
标题必须符合以下公式之一，不能瞎写：

1. **疑问+数字承诺**：[痛点疑问] + [权威身份] + [数字] + [承诺]
   - 例："买运动轮椅别瞎选！康复师告诉你3个必看指标"
   
2. **警告+反常识**：[反常识断言] + [品类] + [数字] + [坑/风险]
   - 例："碳钢轮椅也会断！图便宜的老人都踩过这3个坑"
   
3. **对比选择式**：[A] 和 [B]，[人群] 该怎么选？
   - 例："手动轮椅还是电动车头？90%的人选错了"
   
4. **清单口诀式**：[购买场景] + [身份否定] + [行动指令]
   - 例："买老年代步车别当小白！销售说啥你都别信，就问这5个问题"
   
5. **教学干货式**：[恐惧痛点] + [时间承诺] + [结果承诺]
   - 例："怕轮椅推不稳摔跟头？30秒教会你怎么选"
   
6. **揭秘式**：[品类] + 的 + [隐藏技能/秘密]
   - 例："运动轮椅的隐藏技能，90%的人不知道"

### 第3步：写开头钩子（前3秒定生死）
前3秒必须用以下钩子之一，不能平铺直叙：

1. **痛点共鸣提问**："很多朋友问我：家里老人到底什么时候该用轮椅？"
2. **反常识否定**："很多人觉得坐轮椅就是认输了？错！"
3. **数字冲击**："90%的人买轮椅都买错了，多花了冤枉钱"
4. **后果警告**："选错轮椅不仅费钱，更是关系到老人的安全"
5. **时间承诺**："今天我用一分钟，给你讲透运动轮椅怎么选"

### 第4步：写4分镜内容（25-30秒）
每条脚本固定4个分镜，每个分镜7秒左右：

| 分镜 | 时长 | 内容要求 |
|---|---|---|
| 镜1 | 0-7s | 钩子+痛点（必须用上面的5种钩子之一） |
| 镜2 | 7-14s | 产品展示+核心卖点1（植入具体参数） |
| 镜3 | 14-21s | 产品展示+核心卖点2（植入具体参数） |
| 镜4 | 21-28s | 总结+行动暗示（不要结尾升华，要口语化收尾） |

**硬性要求**：
- 每条必须植入至少2个具体参数（型号、重量、尺寸、材质等）
- 必须口语化，像跟朋友聊天，不能像念稿子
- 不要结尾升华（"愿天下老人都能..."这种不要）
- 不要提"医用级""医疗器械""医院康复科"等敏感词

### 第5步：自检（交付前必须过一遍）
- [ ] 标题符合6种公式之一？
- [ ] 开头钩子用了5种钩子之一？
- [ ] 4个分镜，每个7秒左右？
- [ ] 植入了至少2个具体参数？
- [ ] 口语化，像活人说话？
- [ ] 没有结尾升华套路？
- [ ] 没有敏感词？

## 四、批量生产模板

每批写脚本时，按以下流程：
1. 确定产品列表
2. 每个产品分配4种不同风格（比如：避坑+痛点+案例+拆解）
3. 每个风格套用对应的标题公式和开头钩子
4. 植入产品速查表里的参数
5. 过一遍自检清单

这样写出来的脚本，每条风格不重复，参数准确，结构完整。
