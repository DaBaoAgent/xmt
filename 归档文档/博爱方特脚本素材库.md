## 一、儿童款 BA-LZ-1 / BA-TZ-1 通用卖点

### 1. 成长可调（核心大卖点）

**【参数】** 坐宽23-46cm厘米级可调，坐深23-50cm毫米级可调，前坐高39-52cm，后坐高37-44cm
**【口语化】** "这台车能从三岁用到十二岁，坐宽坐深坐着高全都能调，孩子长个子它跟着长"
**【画面】** 同一个孩子不同年龄段坐同一台车的对比画面 / 家长用扳手调节坐宽的特写
**【钩子】** "别人家轮椅用两年就小了，这台能用六年"
**【情感线】** 省钱、省心、陪伴成长、不浪费

### 2. 六年使用周期

**【参数】** 用户自主调节可用约3年，3年后返厂全车架调节保养可再用约3年
**【口语化】** "前三年自己在家调，三年后寄回厂家免费调一次，又能再用三年"
**【画面】** 时间轴动画：3岁→6岁→9岁→12岁，同一台车
**【钩子】** "一台车的钱，用两台车的时间"
**【情感线】** 长期主义、物超所值、厂家负责到底

### 3. 七色可选

**【参数】** 红、紫、粉、蓝、黑、金、白，共7色
**【口语化】** "红橙黄绿青蓝紫，孩子喜欢什么颜色就选什么颜色"
**【画面】** 7台不同颜色轮椅并排展示 / 孩子指着粉色说"我要这个"
**【钩子】** "轮椅也能是孩子喜欢的样子"
**【情感线】** 尊重孩子审美、不自卑、个性化

### 4. 推把适配家长身高

**【参数】** 推把高度可调，把手可折叠收纳
**【口语化】** "爸爸推调高一点，妈妈推调低一点，不用弯腰驼背"
**【画面】** 高个子爸爸和矮个子妈妈分别推同一台车，推把高度不同
**【钩子】** "推孩子出门，腰不酸了"
**【情感线】** 体贴家长、人性化设计、细节见真心

### 5. 标配安全带

**【参数】** 海绵衬垫+尼龙带，分大号小号
**【口语化】** "标配五点式安全带，孩子坐上去牢牢固定，家长放心"
**【画面】** 家长给孩子系安全带的特写 / 孩子在轮椅上活动不滑动
**【钩子】** "安全这事儿，不能省"
**【情感线】** 安全感、保护、家长放心

### 6. 标配防翻轮

**【参数】** 铝合金，前后高低可调，可上翻折叠
**【口语化】** "后面两个防翻轮，上坡下坡不往后仰，过坎不往前栽"
**【画面】** 轮椅上坡时防翻轮触地的慢动作 / 折叠防翻轮的特写
**【钩子】** "孩子坐的车，稳比什么都重要"
**【情感线】** 安全、稳定、保护

### 7. 碳纤维脚踏板（三维可调+上翻）

**【参数】** 碳纤维，高低/前后/角度可调，坐宽33cm以上可上翻
**【口语化】** "脚踏板碳纤维的，轻还结实，高低前后角度都能调，上下轮椅一翻就上去"
**【画面】** 脚踩脚踏板的特写 / 上翻脚踏板方便孩子上下轮椅
**【钩子】** "一个脚踏板，都用碳纤维"
**【情感线】** 用料扎实、细节考究、轻量

### 8. 碳纤维硬靠背

**【参数】** 碳纤维或铝合金+聚氨酯发泡绵，分半包裹/浅包裹，大小高低角度可调
**【口语化】** "靠背是碳纤维的，硬挺但不硌，孩子坐上去腰是直的，不驼背"

### 9. 快拆大轮

**【参数】** 后轮充气胎20/22/24/25寸，快拆轴，外展角度1.5°
**【口语化】** "大轮子一按就拆，放后备箱不占地方，出门旅行带着走"
**【画面】** 单手按下快拆按钮取下大轮 / 轮子放进汽车后备箱
**【钩子】** "带孩子出远门，轮椅也能上飞机"
**【情感线】** 出行自由、不被束缚、说走就走

### 10. 极致轻量化

**【参数】** 铝合金款净重12.5-13.5kg，钛合金款净重12-13kg

## 六、脚本结构模板

### 模板A：10秒口播（一字开头）

```
[0-2秒] 钩子画面 + 一字开头价格/数字
[2-5秒] 核心卖点（1个）
[5-8秒] 场景化展示
[8-10秒] 行动号召
```

示例（儿童款）：
> "6年！这台轮椅能从三岁用到十二岁，坐宽坐深全可调，孩子长个子它跟着长，昆山工厂直发，评论区扣1发价目表。"

### 模板B：30秒种草（痛点→方案→证明）

```
[0-5秒] 痛点场景（孩子轮椅又小了/推轮椅腰酸/出门不方便）
[5-15秒] 产品出场 + 核心卖点（2-3个）
[15-25秒] 细节展示 + 使用场景
[25-30秒] 售后保障 + 行动号召
```

### 模板C：感人煽情（故事型）

```
[0-5秒] 情感画面（孩子渴望出门/家长疲惫）
[5-15秒] 转折（遇到这台轮椅）
[15-25秒] 改变（生活因轮椅而不同）
[25-30秒] 升华 + 品牌露出
```
