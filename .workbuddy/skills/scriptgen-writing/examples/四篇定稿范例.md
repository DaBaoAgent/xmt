# 四篇定稿范例（对标原句 → 改后）

每篇都按「骨架照搬 + 词级近义替换」改写：保留对标每句的句式骨架、语序、节奏，
但每个词换成我们的近义表达。新稿可直接参照这四篇的改法。

看的时候重点关注：改之前先读「对标原句」，再看「改后」是怎么一句对一句替换的。

## 个人号 ｜ 挑代步车先问这几个问题
**成稿**：238 字 / 56.7 秒（目标 65 秒）｜ 产品口径：品类
**对标**：顾店长-派斯莱德老年代步车 ｜ 买老年代步车一定要这么问，可以帮你避开90%的坑#派斯莱德# ｜ 时长 45.3s

### 对标原句

```
买代步车不要再当小白了，进店不管他怎么说，你就淡定的问他几个问题。
第一，什么车架？
车架决定了整车的重量，提前问可以避开自重比较重的车型，优选铝合金车架，不要碳钢车架。
第二，什么电机多少瓦？
动力决定了爬坡能力。
优选有刷电机不低于500瓦，无刷电机不低于300瓦。
第三，什么电池？
铅酸电池还是锂电池？
预算充足建议选锂电池。
比较轻，使用频率高就选大电池。
第四，什么刹车？
电磁刹车还是电子刹车？
首选电磁刹车，断电不溜坡，安全第一。
第五，轮胎是实心轮胎还是充气轮胎？
省心就选实心轮胎。
把这些问题记在手机里面，照着问一遍，能够帮你避开90的坑。
只卖对的，不卖贵的。
关注顾店长，智能代步更放心！
```

### 改后

```
挑代步车别再当小白了，进店不管他咋说，你稳当点问他几个问题。
头一个，什么车架？车架决定整台车有多重，挑轻的铝的，别要铁的。
第二个，什么电机？多大功率？动力管的是上坡费不费劲，别光听人吹。
第三个，什么电池？是铅酸还是锂电？手头宽裕就上锂电。
第四个，什么刹车？电磁的还是电子的？选电磁的，松手就停，坡上不溜。
第五个，轮胎是实心还是充气？图省事就挑实心的。
这几条往手机里记一下，到店照着问一遍，能避开大部分坑。
不卖贵的，只卖对的。我是小冯，在苏州阳光大厦九一一室，来了我陪您试一圈。
```
