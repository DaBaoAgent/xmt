# 速查卡

## 出稿四步

```bash
# 1. 提对标（要 segments，不要只提全文）
.venv/Scripts/python.exe -c "
from scriptgen.sources import RedFoxExtractor
o=RedFoxExtractor().extract_channels('<URL>')
[print('[%.1fs] %s'%(s.get('start',0),s.get('text'))) for s in (o.get('transcript') or {}).get('segments') or []]"

# 2. 查人设（写稿前必读）
#    config/personas.json → personas[] → 找 id 匹配的
#    看 identity / voice / sentence_patterns / cta_style / duration

# 3. 出稿 + 改稿
.venv/Scripts/python.exe -m scriptgen add "<URL>"
.venv/Scripts/python.exe -m scriptgen revise <CODE> --instruction "<要求>"

# 4. 刷全部产出 + 清旧文件
.venv/Scripts/python.exe tools/archive_scripts.py
```

## 人设速查

| id | 身份 | 时长 | 字数 | CTA | 关键禁忌 |
|---|---|---|---|---|---|
| `oral` | 翔哥·十年辅具·邻居家懂行 | 60-90s | 260-400 | 关注/转给 | 不硬推销 |
| `brand` | 心悦提问·小冯实操 | 30-45s | 150-240 | 到店试车 | 不堆功能点、≤3质疑点 |
| `personal` | 小冯·工厂店·朴实口音 | 45-60s | 200-280 | 来展厅 | — |

**时长真目标 = 人设区间 ∩ 对标时长的 80%-120%**，查 `sg_scripts.target_seconds`。

## 改写口诀

**骨架照搬，词换近义；只动三类：换词、调位、替内容。**

对标：只卖对的，不卖贵的。
我们：不卖贵的，只卖对的。（调位置）

对标：这都是我在评论区看到的。
我们：这话我天天能在评论区看到。

对标：谁让你坐我新车的？
我们：你坐我车上了。（保住「坐我的新车」这个前提，否则下一句接不上）

## 三查

1. **查逻辑链** —— 第一个质疑有回应吗？主语跳了吗？「您」「你」统一吗？
2. **查书面词** —— 副车架/分量/碳钢/瞅见/搁/瞅瞅/样式/稳当/控速/灵敏/座宽/轮组/体验中心
3. **查合规** —— 价格？「多少钱」？加微信？绝对化？「更安全/更稳/不会翻」？

## 必回查知识库

产品动作不能凭印象：F2Q 折叠是「按钮往外一拉，一压完成折叠」（专利 ZL2020 2 092755.4），
**不是**「两段一压一扣拆开」。

## 人工定稿模式

LLM 改双人对话稿极易跑偏。压不动就人工写（参考 `tools/rewrite_all_align.py`）：

```python
body = {"format":"dialogue","lines":[{"speaker":"心悦","beat":"钩子","text":"..."}]}
body_text = body_plain_text(body)       # dialogue 保留「说话人：」
spoken = util.strip_speakers(body_text) # 时长字数只算台词
scan = compliance.scan_script(body_text, {"disclaimer":disc}, "", FACT_TEXT, [])
```
⚠️ 必须传 `FACT_TEXT`，否则「19 公斤」会被误判 `numeric_unverified`（知识库写「19 KG」）。

## 踩坑（别再犯）
