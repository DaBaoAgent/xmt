## 人设速查

| id | 身份 | 时长 | 字数 | CTA | 关键禁忌 |
|---|---|---|---|---|---|
| `oral` | 翔哥·十年辅具·邻居家懂行 | 60-90s | 260-400 | 关注/转给 | 不硬推销 |
| `brand` | 心悦提问·小冯实操（**也可单人出镜**） | 30-45s | 150-240 | 到店试车 | 不堆功能点、≤3质疑点 |
| `personal` | 小冯·工厂店·朴实口音 | 45-60s | 200-280 | 来展厅 | — |

**时长真目标 = 落在人设区间内**（对标超上限取上限、低于下限取下限），查 `sg_scripts.target_seconds`。
用户说「简单一点」→ 字数往下压一档（150-200 字 / 36-48 秒）。

## 改写口诀

**骨架照搬，词换近义；只动三类：换词、调位、替内容。**

对标：只卖对的，不卖贵的。
我们：不卖贵的，只卖对的。（调位置）

对标：这都是我在评论区看到的。
我们：这话我天天能在评论区看到。

对标：谁让你坐我新车的？
我们：你坐我车上了。（保住「坐我的新车」这个前提，否则下一句接不上）

## 四查

1. **查长度** —— 我方秒 / 对标秒 在 **0.8-1.3 倍**内？超了就是加戏了
2. **查逻辑链** —— 第一个质疑有回应吗？主语跳了吗？「您」「你」统一吗？
3. **查书面词** —— 副车架/分量/碳钢/瞅见/搁/瞅瞅/样式/稳当/控速/灵敏/座宽/轮组/体验中心
4. **查合规** —— 价格？「多少钱」？加微信？绝对化？「更安全/更稳/不会翻」？

## 长度与 CTA

**长度贴对标，不贴人设区间**。对标 21 秒就写 21 秒，不凑人设下限。
一句对一句，不加不减 —— 不补展厅细节、不补「我是某某」、不补结尾话术。

**CTA 跟着对标走，不是每篇都塞**：
- 对标结尾是陈述句（「不用总麻烦人」「说停就停，说走就走」）→ **不加 CTA**
- 对标结尾是行动号召（「关注顾店长」）→ 保留一句，但**不写具体门牌地址**
- 拍摄提示里也不要写「字幕突出 XX 路 XX 号」

> 用户原话：「太长了 要和原稿差不多的 而且不一定每个脚本都要带地址」

## 必回查参数档案

产品动作/参数不能凭印象，**先查 `docs/产品参数档案.md`**：

| 型号 | 关键参数 | 注意 |
|---|---|---|
| F2Q | 19KG、240W、六重保护、44cm | 无具体续航 km，别编 |
| P10 | 15.8KG、340W、15km、34cm | 别把 F2Q 的 19/240 抄过来 |
| P11 | **无数字** | 只写结构卖点，不写重量/续航 |
| NIP | 7.8kg、150kg、810-913mm | **手动款**，刹车是手拉线刹 |
| 朋友2 | 多档高度、网布袋、线控刹车 | 别混减震款的 8.9KG/8档7档 |
| 减震款 | 8.9KG、8档+7档 | 只此一款，别写到朋友2 |
| GB-819 | 180LM、>100分贝、四脚底座 | 「高于100分贝」别省 |
| 小飞燕 | 95°/145°两档、防后倾小轮 | **手推车无电机** |

★ 竞品参数（16公斤/12公里/陀螺仪/大阻尼）绝不抄。
★ 手动款禁用词：电机、电池、摇杆、电磁刹车、瓦、AH、锂电、续航、遥控。

## 人工定稿模式

LLM 改双人对话稿极易跑偏。压不动就人工写（参考 `tools/rewrite_all_align.py`）：

```python
body = {"format":"dialogue","lines":[{"speaker":"心悦","beat":"钩子","text":"..."}]}
body_text = body_plain_text(body)       # dialogue 保留「说话人：」
spoken = util.strip_speakers(body_text) # 时长字数只算台词
scan = compliance.scan_script(body_text, {"disclaimer":disc}, "", FACT_TEXT, [])
```
⚠️ 必须传 `FACT_TEXT`，否则「19 公斤」会被误判 `numeric_unverified`（知识库写「19 KG」）。

## 踩坑（别再犯）

1. 另起炉灶写全新话术 ❌
2. 只换地点其余照抄 ❌
3. 照搬对标角色设定（老人抬杠 → 20岁店员）❌
4. 只换字面不管逻辑链 → 读不通 ❌
5. 产品动作/参数凭印象编 ❌
6. 按人设上限压时长 ❌
7. 口语化时带回价格词 ❌
8. 改标题后不清旧 docx ❌
9. **抄对标的竞品参数** ❌（他说 16 公斤，我们 P10 是 15.8 公斤）
10. **标题带标点** ❌（slugify 转连字符 → 安全钩子拦 out/*.docx）
11. **Word 序号不接续** ❌（store.docx_path 用数据库 id，会跳号）
12. **新 code 不进 ORDER** ❌（TXT 不出、账号内序号断档）
13. **批量稿收尾句撞车** ❌（写完跑一次全库去重检查）

## 收尾句去重检查（批量稿必跑）

```bash
.venv/Scripts/python.exe -c "
import sqlite3
con=sqlite3.connect('data/xmt.db')
lasts={}
for r in con.execute(\"select code,title,body_md from sg_scripts where account_label='个人号' order by id\"):
    l=[x for x in r[2].split(chr(10)) if x.strip()][-1]
    lasts.setdefault(l,[]).append(r[1])
for l,v in lasts.items():
    if len(v)>1: print('重复:',l,v)
"
```
