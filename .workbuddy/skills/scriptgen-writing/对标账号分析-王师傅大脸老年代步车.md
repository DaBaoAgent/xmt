## 三、风格拆解（个人号可直接套）

### 3.1 语言特征
1. **人称**：「咱们」为主（比陈大脸的「您/咱们」更偏「咱们」），第二人称少
2. **开头爱用钩子问句/悬念**：
   - 「是谁还没看过这款…你不会没看过吧？」
   - 「选择功能老年代步车一定要先看看咱们这款…」
   - 「在生活中碰到这种十度左右的小坡，推行是非常轻松的」
3. **口语标记词多**：「呢」「啊」「吧」「咱们」「最绝的是」「而且」「而且…」
4. **句子短、逗号多**（②那种一句到底的连缀写法最典型）
5. **参数口语化**：说「12公里」不说「续航12km」，说「16公斤」不说「15.8KG」
6. **结尾带一句情绪收束**：「真是活该他活呀」「护理变得更轻松」——比我们现有的收尾更软

### 3.2 三种骨架

| 骨架 | 步骤 |
|---|---|
| **悬念钩子型** | 抛一个数字/悬念问句（「1000多万人看过」）→ 逐条说功能（电动代步→助行→康复→助推）→ 报重量续航 → 情绪收尾 |
| **连缀介绍型** | 一句「一定要先看看咱们这款」→ 用逗号把 6-7 个卖点串成一句 → 收在「省空间」 |
| **实测答疑型** | 抛场景（碰到十度小坡）→ 说原理（电动助力/陀螺仪）→ 给结论（会带咱们上来/下坡非常慢）→ 「OK」收尾 |

## 五、套用建议（我们写个人号时）

1. **开头用悬念问句**，比「这个就是XX产品」更抓人：
   - 「这轮椅能带上飞机吗？」（我们已用，方向对）
   - 「谁还没见过这台车？」
2. **句子要短、逗号可以连缀**（②那种写法），别每句都断开
3. **参数口语化**：「15.8公斤」说成「才十五点八公斤」，「340W」说成「170瓦电机装两个」
4. **收尾要软一点、带情绪**，不全是「评论区说说」
5. **⚠️ 竞品参数绝对不能抄**：他说的 16 公斤 / 12 公里 / 陀螺仪 / 大阻尼康复模式，都是**他那台四合一代步车**的参数。我们写 P10（15.8KG / 15km / 电磁刹车）要用自己的数。
6. 骨架优先级：**悬念钩子型 > 实测答疑型 > 连缀介绍型**。连缀型虽然最像他的口吻，但信息密度太高、参数容易堆错。
