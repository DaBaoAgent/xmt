# 展厅分镜脚本技能（无对标出稿模式）

> 来源：`jiaoben/` 文件夹里沉淀的三套合集 + 17 个生成器（gen_*.py），
> 2026-10-23 学习后固化到本技能。**这是「贴对标原句改写」之外的第二条出稿路线。**

## 什么时候用哪条路

| 场景 | 用哪个 |
|---|---|
| 用户给了对标视频链接 | `SKILL.md` 铁律一「贴对标原句改写」 |
| 没有对标，但展厅里有实拍产品 | **本技能：展厅 4 分镜** |
| 一个产品要批量铺多个角度/给销售当素材 | 本技能（一产品 4 套，角度不重样） |
| 双人抬杠对话稿 | 走对标路线（皮皮熊骨架），本技能不产对话稿 |

两者共用同一套合规红线（`config/compliance.json`）、人设卡和产品参数档案，
**本技能不引入新参数口径，只新增「结构 + 风格 + 角度」打法**。

---

## 铁律一：结构就是 4 分镜 × 7 秒，一秒不加

每条脚本固定 4 个镜头、每镜 7 秒、全长 28 秒。jiaoben 三套合集 64 条全部这个结构，
不是巧合，是**被市场验证过的完播率结构**：

| 镜 | 时间 | 职能 | 画面要求 |
|---|---|---|---|
| 镜1 | 0-7s | **钩子** | 人 + 动作入画（蹲/站/拎/推），一句痛点问句或反常识陈述 |
| 镜2 | 7-14s | 第一卖点 | 手指向产品 + 一个可拍的动作（拍车架/捏刹车/拎起来） |
| 镜3 | 14-21s | 第二卖点 | 换角度或换场景（对比另一台/换个人称/演示折叠） |
| 镜4 | 21-28s | **收尾** | 情绪句或价值句收，不喊口号、不逼单、不报价 |

每镜的文本格式（生成器和合集都用这个）：

```
镜1（0-7s）：展厅里，主播对着镜头
  买助行器别光图便宜，这3个坑踩一个后悔半年。
```

- 第一行是**画面描述**（给摄像看），第二行是**口播文案**（给出镜人念）
- 画面描述里必须写清动作，不能只写「主播介绍产品」——没法拍
- 口播一句 15-25 字，长句拆两句

> 反例（旧稿踩过）：镜2 画面写「主播讲解座椅功能」→ 摄像问「讲解啥？怎么讲？」。
> 正例：「主播翻下座椅坐上去，又翻回来」。

## 铁律二：一个产品 4 套，角度不重样

jiaoben 的实证打法：**每个产品每次出 4 套，4 套各打一个角度**，
标题直接标明风格，方便销售按渠道挑。

### 角度矩阵（从 64 条实证脚本归纳）

| 角度 | 核心手法 | 适用 | 实证标题 |
|---|---|---|---|
| 避坑指南风 | 先说「别只看价格」，再给 2-3 个判断点 | 全品类 | 买助行器别只看价格，这3个坑别踩 |
| 亲戚口碑风 | 熟人真实故事切入（我舅/我妈/我媳妇） | 助行器/轮椅 | 我舅用了三个月，现在天天逛公园 |
| 反常识风 | 「你以为 X 只是 Y？」打破品类刻板印象 | 助行器/代步车 | 你以为助行器只是扶着走 |
| 老板吐槽风 | 从业者身份背书（我卖了五年） | 全品类 | 这个车我卖了五年，没一个人回来差评 |
| 场景故事风 | 具体顾客/具体一天，像讲昨天的事 | 全品类 | 昨天有个阿姨来店里，说这个车救了她 |
| 对比反差风 | 先踩便宜货/旧认知，再亮本款 | 全品类 | 之前贪便宜买过一个，花了800，扔了 |
| 颜值切入风 | 颜色/外观破「老年车=丑」的刻板印象 | 多色款 | 助行器也能这么好看 |
| 功能拆解风 | 单点深挖一个设计（翻折座椅/快拆轮） | 结构亮点款 | 这个翻折座椅，设计的人是天才 |
| 踩坑吐槽风 | 第一人称翻车经历（我就是踩坑了） | 康复类 | 骨折康复期，千万别拄拐 |
| 用户视角风 | 「第 N 天，我终于能……」日记体 | 康复类 | 脚崴了第3天，我终于能下楼了 |
| 对比科普风 | 两个品类的使用边界（助行器 vs 小福车） | 相邻品类 | 助行器和小福车，到底有啥区别 |
| 黑科技风 | 「你见过吗」式惊叹 + 演示 | 电动款 | 手机APP遥控，人在楼下就能把车开上来 |
| 家庭场景风 | 老人从「怕麻烦」到「天天往外跑」的转变 | 轻便款 | 我妈以前出门怕麻烦，现在天天往外跑 |
| 参数拆解风 | 一个硬参数讲透（170W双电机/电磁刹车） | 电动款 | 170W双电机，上坡不费劲 |
| 中老年痛点风 | 安全恐惧开场（坡上溜车） | 电动款 | 老年代步车最怕啥，坡上溜车 |
| 女生视角风 | 「我一个女生也能……」反差举证 | 轻便款 | 我一个女生，也能把这个车拖走 |
| 极简风 | 就一个按钮/一个动作，上车就会 | 电动款 | 就一个按钮，老人上车就会开 |
| 细节控风 | 后轮快拆/坐垫透气/靠背两档 | 全品类 | 这个后轮快拆，设计的人太懂了 |
| 夏天痛点风 | 季节性痛点（坐垫闷疹子） | 带座款 | 夏天坐轮椅屁股长疹子，换个坐垫试试 |
| 安全风 | 「最怕啥」+ 结构举证（双X交叉） | 全品类 | 推起来稳不稳，看这个结构 |
| 王师傅偶遇风 | 「哎你这个是啥」围观式提问，适合多SKU展厅 | 博爱方特/新芝系 | 手动轮椅加个这个，就变电动了 |
| 方庄店介绍风 | 导购式讲选购逻辑/售后政策 | 博爱方特/新芝系 | 儿童康复轮椅怎么选，看这三点 |
| 旅游痛点风 | 出行场景（上高铁/上飞机/后备箱） | 折叠款 | 带老人旅游，这个车能上高铁 |

### 4 套的配比公式（实证）

```
痛点/避坑类 ×1（拉完播）  口碑/场景故事 ×1（拉信任）
功能/参数 ×1（给决策理由）  反差/黑科技/颜值 ×1（拉传播）
```

同一批 4 套里，**卖点不重复**：脚本1 讲刹车、脚本2 就不能再讲刹车，
换重量/折叠/材质/场景。翻过车：NIP 两套都讲「松手即刹」，用户说「怎么又是刹车」。

## 铁律三：标题公式

```
【脚本N】（风格名）：钩子句
```

- 钩子句 = 痛点问句 / 反常识陈述 / 具体场景，**10-18 字**
- 风格名用上表里的原名，方便后期按风格检索复用
- 文档内标题可以带问号；**但落 Word/TXT 文件名时必须去掉标点**
  （slugify 会把问号转连字符，触发本机安全钩子拦 `out/*.docx`，见 SKILL.md 铁律八）

## 铁律四：语言——口语化 + 活人感

jiaoben 全部 64 条的共同语感，六个可执行点：

1. **短句**：一句一个信息，15-25 字；超过 30 字的口播删成分号两句
2. **数字口语化**：「才7.8公斤」「10公斤出头」「400克，比一瓶水还轻」——
   不写「净重 7.8kg」，不写「仅重」
3. **产品名带一次全名，之后用「这个」**：镜1 说「NIP」，镜2 起说「这个」
4. **动作动词优先**：拍、拎、捏、翻、晃、按、拖、塞——每个镜2镜3 必须有一个
5. **不写书面词**（同 SKILL.md 铁律四对照表）：副车架→架子、分量→有多重、
   轮组→轮子、控速→自己会慢下来
6. **收尾用情绪句不用推销句**。实证收尾库：
   「老人能动起来，比啥都强」「安全第一」「轻才是真的好」「设计的人真的懂用户」
   「先试后买，放心」「你的世界不再有边界」
   ★ **批量稿收尾句必须全库不重复**（跟 SKILL.md 铁律一同一个坑，写完跑去重检查）

## 铁律五：产品数据只能来自档案和 jiaoben 产品资料

- 第一来源：`docs/产品参数档案.md`（2026-10-23 已把 jiaoben 全部产品资料并入）
- 第二来源：`jiaoben/<产品名>/产品信息.txt`、`参数卖点宣传词.txt`、`产品卖点.txt`
- **旧脚本里的数字要重新核对**，见下方坑 1
- 手动款（NIP/朋友2/913/医用级/海豚/拐杖系/小飞燕/小福车/博爱方特运动轮椅）
  禁写：电机、电池、摇杆、电磁刹车、瓦、AH、锂电、续航、遥控
- 电动款（F2Q/P10/P11/新芝车头）才能写电机、续航、时速

## 铁律六：合规（SKILL.md 铁律六之外，本技能新增三条）

| 新增规则 | 原因 |
|---|---|
| 钩子问句避开「多少钱/什么价」字样 | 旧 36 套有「钛合金的轮椅？这得多少钱？」，`price` 规则连问句一起扫；改成「钛合金轮椅，你见过吗」 |
| 名人只陈述事实，不写「背书/推荐」 | 陆鸿（感动中国人物）是事实，可写「他自己就坐轮椅」；「名人背书，靠谱」这种结论句不写（`endorsement`） |
| 质保/售后只写品牌官方政策原文 | 博爱方特铝架保5年/钛架保6年是官方政策可写；「终身售后」不写（`warranty_claim`）；「年销10个亿出口」不进稿（宏大宣传无可验证出处） |

## 产出规范

| 产物 | 位置 | 方式 |
|---|---|---|
| 合集 TXT | `jiaoben/<合集名>.txt` | `tools/make_showroom_scripts.py` |
| 打印版 DOCX | `jiaoben/<合集名>.docx` | 同上（需 python-docx，版式照 24 套定稿：标题居中、产品一级标题、脚本二级标题、镜号加粗） |
| 自定义批次 | `out/展厅分镜脚本/<合集名>.txt` | `--spec spec.json --out out/展厅分镜脚本` |

生成器用法：

```bash
.venv/Scripts/python.exe tools/make_showroom_scripts.py                    # 内置小福车4套示例
.venv/Scripts/python.exe tools/make_showroom_scripts.py --spec my.json     # 自定义产品+角度
.venv/Scripts/python.exe tools/make_showroom_scripts.py --products 小福车   # 只出某个产品
```

spec JSON 结构（见生成器 docstring）：products[] → scripts[] → shots[]（desc/text），
style 必须在风格库里，工具会校验，不合规直接报错不产出。

## 坑（别再犯）

1. **旧脚本数字失传**：24 套里 P10 写「才10公斤」——那是**车架约 10KG**，
   整车 15.8KG。复用旧合集前先对照档案改数。A3 的「10.4公斤」同样待知识库核实。
2. **小飞燕不是电动车**：旧稿曾写电机/摇杆/钥匙/电磁刹车，已删。
   它是手推椅车，跟小福车一样禁写电动词。
3. **朋友2 的重量别跟 NIP 混**：两个都是 7.8kg（各自产品文件都这么写），
   但承重不同（NIP 150kg / 朋友2 120kg），卖点话术不能互抄。
4. **「多少钱」钩子**触发 price 规则（见铁律六）。
5. **同产品 4 套卖点重复**（见铁律二配比公式）。
6. **画面描述不可拍**（「主播讲解功能」式描述退回重写）。
7. **博爱方特/新芝是经销品牌不是佳康顺本牌**：稿里品牌名按资料写全
   （博爱方特/新芝动力），别写成佳康顺；佳康顺「17年匠心工厂直营」的
   背书只能用在佳康顺产品上。
